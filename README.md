## 📌 Overview

**Dilan Construction & Enterprises** is a premier civil engineering and construction company operating across Sri Lanka. With over a decade of proven on-site expertise, we offer complete turnkey residential and commercial building construction—guiding clients seamlessly from initial architectural blueprints and BOQ estimates through to turnkey handover.

This repository hosts the official, high-performance, bilingual marketing and customer-intake web platform for **Dilan Construction & Enterprises**.

---

## ✨ Key Features

- 🌐 **Full Bilingual Experience (සිංහල & English)**: Complete instant language switching across all headings, service descriptions, modals, badges, and cost estimators.
- 🌓 **Dynamic Theme Switching (Dark / Light)**: High-contrast, clean theme switcher with automatic user preference persistence via LocalStorage.
- 📐 **Interactive Construction Cost Estimator**: Real-time project budget calculator calculating estimates based on floor area (sq. ft.), number of floors, structure type, and service tiers (Basic, Standard, Luxury).
- 📱 **100% Responsive Architecture**: Optimized for fluid display across mobile handsets, tablets, laptops, and ultra-wide desktop monitors.
- 🖼️ **Portfolio & Official Flyer Showcase**: Interactive visual showcase of ongoing and completed architectural and residential projects, including high-resolution view of the official company promotional flyer.
- 💬 **Instant Multi-Channel Connect**: One-click WhatsApp direct chat, phone call launcher, and inquiry contact forms with embedded Google Map integration.
- 🔍 **SEO & Accessibility Optimized**: Built-in Schema.org `GeneralContractor` JSON-LD structured data, Open Graph tags, fast loading, and semantic HTML5 layout.

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/sachintha629/Dilan_Construction.git
# or
git clone https://github.com/DILAN-CONSTRUCTION-ENTERPRISES/Contact.us.git
```

### 2. Run the Site
The site is built with pure, modern vanilla web standards (HTML5, CSS3, ES6 JavaScript) without external build steps or heavy dependencies:

- **Option A (Direct File)**: Double-click or open `index.html` in Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari.
- **Option B (VS Code Live Server)**: Right-click `index.html` inside VS Code and choose **"Open with Live Server"**.
- **Option C (Local HTTP Server)**:
  ```bash
  # Using Python 3
  python -m http.server 8000
  ```
  Then navigate to `http://localhost:8000` in your browser.
